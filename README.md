# 红树林蓝碳秘密 · 地下碳宝库 🌱

一个面向小学生的红树林蓝碳互动科普小游戏。单文件网页应用，无需安装，点开即玩。

## 玩什么

- **① 碳的旅程**：跟随一粒碳，看它如何在 100 年里被"埋"进红树林脚下的泥土，形成地下碳宝库
- **② 对比实验**：一场公平比赛——普通森林 vs 红树林，谁锁得住碳？
- **③ 命运的选择**：这片林子的命运由你签字决定。4 个方案、多轮决定、13 个结局
- 画面里藏着 **8 个知识彩蛋**，点击发光的圈圈解锁

## 在线玩

- GitHub Pages：`https://<你的用户名>.github.io/mangrove-blue-carbon/`（开启 Pages 后生效）

## 数据说明

土壤碳占比 49–98%、储碳为普通森林 3–4 倍、破坏 1 公顷释放 500–1000 吨碳、
全球已损失 35–50% 等数据取自明湾学校七年级近海生态研究项目资料，为科普量级估算；
碳汇交易数据引用 2023 年全国首单红树林碳汇拍卖（485 元/吨，3,875 吨成交 187 万元）。

## 运行

无需构建。直接双击 `index.html`，或用任意静态服务器托管。

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 技术

单文件 HTML + 原生 JavaScript + 动态 SVG，零依赖、零构建。
